晋级规则

默认每轮 100 局：50 个环境 seed，交换先后手。Serving 搜索：温度 0、根噪声 0、每动作新增 128 次模拟，并复用回合内子树。实际配置显示在各轮明细。

晋级胜率 =（胜局 + 0.5 × 平局）/ 总局数。完整对战后达到 50% 即晋级，包括恰好 50%。未晋级仍保留最新 checkpoint 用于续训；下一轮采样继续使用当前最优模型。

指标口径

P1/P2 为先手/后手；候选/最优为模型身份，交换先后手后保持对应关系。宽度同时记录根合法动作数和已访问动作数；深度为新增模拟路径的原子动作数。

Search value 为根节点访问加权回传 utility，network value 为原始网络 utility。utility = rank + 0.25 relative + 0.05 absolute；均为当前行动玩家视角。继承差值仅统计继承 visits > 0 的子节点。

Policy 分别记录合法 NN 分布与搜索监督分布；entropy 使用自然对数。训练均值按消费 rows 加权；gradnorm 为每个参数张量裁剪前的 L2 norm。均值、Std 和有效样本数见轮次明细。
