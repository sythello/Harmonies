# v001-fixed32：固定 32 模拟基线

[返回版本索引](../README.md)

**状态：完整 10/10 轮，原始核验通过。** 历史 run 名称：`selfplay-10rounds-20261015`。本版于 2026-10-29 统一登记；该日期不是训练日期。

## 本版方案

- 首个完整 10 轮正式实验，包含 replay window、100 局 gatekeeper 和 best/latest 分离。
- 每轮 1000 局；每个原子决策新增 32 次模拟，根噪声 0.25，温度 1，回合内复用树。
- 全部状态进入 replay；每轮固定训练 400000 行，窗口内每遍无放回，遍数不限。
- 训练和晋级看板均包含终局分数、入住动物数、完整动物牌数。

完整配置见 [config.json](run/config.json)，结构化结果见 [manifest.json](manifest.json)。网络为 `128 → 128` 共享 FFN；三个 value head 与 policy head 均为单层线性输出，rank 额外使用 tanh。
