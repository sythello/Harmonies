# v003-spatial：双向三角与六边形空间 kernel

[返回版本索引](../README.md) · [网络结构与完整测速说明](../../../../docs/ai-rl-scaling.md)

**状态：10轮训练已完成并通过全量数据核验；400局独立对战已完成。**

## 相对 v002 的改动

- 保留全部旧输入；从双方版图的单格 one-hot 提取共享局部特征。
- 3 格三角、6 格三角各两个方向，加上 7 格六边形，共 5 组独立 kernel，每组 16 channel，Linear + ReLU。
- 每组在双方各 23 格锚定，越界邻格使用独立的第 30 类。位置和双方之间共享权重，方向之间不共享。
- 空间输出 3680 维，拼接原来的 1654 维，得到 5334 维；主干扩展到 `512 → 128`。
- policy、rank、relative、absolute 各增加独立的 64 维 ReLU 隐层。参数量从 343,555 增至 **2,900,467（8.44×）**。
- 特征 schema 仍为 v2，模型架构为 `spatial-v3`；旧模型和 replay 兼容。训练与 serving 使用相同几何索引。

## 正式 10 轮训练结果（2026-10-29–30）

使用 seed 1729 从随机权重独立训练，未加载测速权重或旧 replay。5 组空间 kernel ×16 channel，主干 512→128，四个独立 tower64，共 2,900,467 参数。生产执行代码冻结在 `run/source/`，配置、patch 和逐文件 SHA256 均保留；启动 HEAD 含未提交实现，不能用 HEAD 单独复现。

每轮 2000 局；每个原子动作独立 25% expensive（新增64模拟、根噪声0.25）/75% cheap（新增16、噪声0）；温度1、回合内复用树，只有 expensive 进入 replay。训练预算 min(400000,2W)，逐遍无放回，每行每轮最多2次；AdamW、batch64、lr0.001、CPU单线程。窗口参数 100000/50000/0.4/0.65 与 v002 相同。每轮100局 serving gate，50个配对种子，新增128模拟、噪声0、温度0；得分率≥50%（平局半胜）晋级，best采样/latest续训。

完成 20,000 局 self-play、1,000 局晋级。共 485,403 个 expensive、1,453,848 个 cheap 决策（expensive 25.0304%）；训练消费 2,794,616 行、43,671 个更新步。**最终 best 是第9轮，latest 是第10轮。** 第10轮46胜0平54负，未晋级。
