# v003 固定 checkpoint 的 value 精度复评

结论：扩大网络后，rank head 仍存在很大的训练/测试泛化差距；在新 self-play 和 serving 对局上，MSE 均显著高于恒预测0的中性基线。不能将这个结论推广为所有 value head 都差于基线，也不能只凭训练/测试差距将原因全部归为过拟合。

本次仅复用已保存数据、重放规则并运行固定模型前向推理，没有训练、搜索新对局、修改模型或 replay。使用本实验冻结源码。最终 best 是第9轮，latest 是第10轮（46% gate，未晋级）。

## 口径与数据

- 训练误差：固定 checkpoint 在本轮实际消费的全部唯一窗口行上重新推理。best9 185,240行、latest10 194,852行，每行实际训练2次；不是在线训练 loss。
- self-play测试：第10轮2,000局、50,184条 expensive样本，双方由 best9 生成；best9未消费这些数据，种子与其训练窗口无交集。与训练采用同一25% expensive64 / 75% cheap16、温度1的采样机制，但策略随训练迭代变化，并非严格同分布随机切分。该集合对 latest10 是训练数据，不能作为它的测试集。
- serving测试：独立400局（200个配对seed）与第10轮gate100局（50个配对seed），每动作新增128模拟、noise0/temp0、回合内复用树。仅统计该模型实际行动时的状态；两模型各自看到的状态不完全相同。
- 每个状态的标签是实际终局，不是搜索估值；MSE对状态等权，再对自己/对手两个输出等权。relative/absolute恢复为分²，除以10000得到训练中的归一化MSE。
- rank标签为−1/0/+1；恒预测0相当于中性胜率50%（平局半胜），基线MSE为非平局状态占比，约1。独立随机猜±1的期望MSE则为该值+1，约2。“高于random baseline”此前应准确理解为高于中性常数基线。
- relative基线为恒预测分差0；absolute基线为该模型训练窗口中分别对两个输出计算的标签均值，测试时不重新拟合常数。结果JSON同时保存各head的0与训练均值基线。

## 置信度与解释

| 数据 | Rank方向准确率（排除平局） | 高置信状态占比（abs(rank)>0.8） | 高置信方向准确率 |
|---|---:|---:|---:|
| best9：第9轮实际训练窗口 | 96.17% | 85.34% | 99.28% |
| latest10：第10轮实际训练窗口 | 96.19% | 86.54% | 99.26% |
| best9：未见过的第10轮 self-play | 60.26% | 64.44% | 65.27% |
| best9：独立400局，对v002 | 57.00% | 84.84% | 58.52% |
| v002 best10：同一400局 | 49.56% | 77.23% | 51.24% |
| best9：第10轮gate中作为对手 | 62.42% | 66.09% | 67.55% |
| latest10：第10轮gate中作为候选 | 61.34% | 69.59% | 66.39% |

best9 在新 self-play 上约60%方向准确率，却仍有约64%状态给出绝对rank大于0.8的预测；这些状态若按概率解释，置信度超过90%，实际方向准确率仅约65%。独立对战中高置信状态约85%，准确率约59%。因此差于中性MSE基线与“方向准确率略高于50%”可以同时成立：错误预测过于自信。

best9 在第7游戏轮及以后，训练rank MSE约0.028，新self-play约1.074，泛化差距仍很大。相同self-play机制下也能看到差距，所以不能仅用serving与探索策略不同解释。但策略演化、对手差异、窗口中旧策略标签、同局状态高度相关，以及单次随机终局标签都可能贡献误差；本次不是严格因果消融，不能确定各原因比例。

绝对分在本次测试仍优于由训练均值构造的常数基线；相对分在新self-play几乎持平，在400局独立对战明显差于0分差基线。因此“所有value head都比random差”不成立。跨版本同一400局中，v003三个head的MSE均低于v002，但它们各自行动状态不同；旧v002最后gate与本次v003最后gate的对手和状态也不同，不能据此精确归因于scaling。

已有数据足以确认单次终局预测误差、训练/测试差距与过度自信。不能据此计算v003的每状态真实条件方差或对条件均值的误差，因为这里每个状态只有一次终局；旧v002的cheap重复续局方差也不能直接移作v003 serving的噪声下限。
