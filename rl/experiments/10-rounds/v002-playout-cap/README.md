# v002-playout-cap：Expensive / cheap 采样

[返回版本索引](../README.md)

**状态：完整 10/10 轮，原始核验通过。** 历史 run 名称：`playout-cap-10rounds-20261018`。本版于 2026-10-29 统一登记；该日期不是训练日期。

## 本版方案

- 相对 v001，每轮 self-play 从 1000 局增加到 2000 局。
- 每个原子决策独立抽样：25% expensive 新增 64 模拟、根噪声 0.25；75% cheap 新增 16 模拟、根噪声 0。两者温度均为 1，回合内复用树。
- 只将 expensive 状态加入 replay；cheap 仍参与真实对局和监控。
- 训练预算从固定 400000 行改为 min(400000, 2 × 实际窗口行数)，每行每轮最多两次。跨轮仍可重复训练。
- 网络、特征、loss、窗口公式、优化器及 gatekeeper 不变。使用与 v001 相同的随机初始权重，独立生成 replay。

完整配置见 [config.json](run/config.json)，结构化结果见 [manifest.json](manifest.json)。网络为 `128 → 128` 共享 FFN；三个 value head 与 policy head 均为单层线性输出，rank 额外使用 tanh。

## 解读与限制

相同初始权重不等于相同训练数据。跨版本 self-play 分数、在线 loss 和晋级胜率不能直接作为棋力排名。2026-10-29 与 v001 的最终 best 进行了 100 局独立 serving 对战：本版 58 胜 / 0 平 / 42 负，得分率 58%，配对种子 95% 区间 47%–68%，尚不足以确认稳定优势。详见 [对比报告](../comparisons/v002-vs-v001-20261029/README.md)。至少 400 局的固定基准项目仍未执行。完整规则、对比口径与后续版本登记要求见总索引。
